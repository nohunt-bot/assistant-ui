# Thread List Sidebar（`aui/threadlist-sidebar`，radix）

Sidebar shell that hosts the thread list beside a thread.

- 直接依賴：`ui/sidebar`, `aui/thread-list`
- 完整安裝順序（依賴在前，含本項）：`ui/utils`, `ui/button`, `ui/separator`, `ui/sheet`, `ui/tooltip`, `ui/input`, `ui/use-mobile`, `ui/skeleton`, `ui/sidebar`, `aui/thread-list`, `aui/threadlist-sidebar`
- npm（整組）：`npm install cn radix-ui class-variance-authority lucide-react @assistant-ui/react@^0.15.36`
